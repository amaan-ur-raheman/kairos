# Context map

Kairos uses separate context documents for the application and package areas in this monorepo. Area context files are created as each domain is established.

| Area | Context |
| --- | --- |
| Web app | `apps/web/CONTEXT.md` |
| Native app | `apps/native/CONTEXT.md` |
| Server | `apps/server/CONTEXT.md` |
| API package | `packages/api/CONTEXT.md` |
| Database package | `packages/db/CONTEXT.md` |
| Environment package | `packages/env/CONTEXT.md` |
| UI package | `packages/ui/CONTEXT.md` |
| Shared config | `packages/config/CONTEXT.md` |
